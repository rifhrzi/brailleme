# Annotated-dot auxiliary supervision preflight

The adopted training-only auxiliary head passed one bounded Torch CPU preflight on 2026-09-06. The exact three candidate source files were then copied to `training/scripts`; `runtime/applied-source-report.json` binds those bytes and the unchanged main reader source. This archive contains source and proof, not a trained recognition candidate or release approval.

The immutable `prototype/` and `runtime/` preparation README/index files intentionally preserve their original pre-execution status. The completed result is `runtime/results/report.json` (SHA-256 `9590846e3afe5e83baa76b0204a18797f8574d14ff9900edb123a41fbdac993b`), supported by `runtime/execution.json`, the process log, RNG traces and the actual augmented batch NPZ. The root archive index binds every retained byte. Runtime scripts keep their original private workspace paths for provenance; these copies are not relocated launchers.

The fixed six TRAIN examples were selected before inference: one Angelina, four DSBI families and one negative. Actual original/prototype Patches RGB, main targets, source order and augmentation RNG were identical with the new path disabled and enabled. There were 36 queries derived from explicit complete-cell DSBI annotations after the existing transforms. Unknown, partial and Angelina cells supply no auxiliary targets. The 11 earlier NumPy/source semantic tests are retained in `prototype/`.

The runtime verified nonzero auxiliary-only gradients into shared fine features, the head and a shared backbone convolution; exact zero loss/gradients for ignored labels; total loss equal to unchanged main loss plus 0.25 times known-point BCE; and main-only validation mode. The validation control used fixed TRAIN Angelina/negative rows with point states omitted, not held validation inputs. One actual Adam step at 2e-5 preserved all 208 arrays in the 52 frozen BN layers.

The original reader still has 829307 parameters and 11 output channels. Reader-only serialization had no auxiliary classes and reloaded with identical outputs, graph and weights; full-wrapper/optimizer state also reloaded. This establishes readability, not support for full CLI resume or interruption-exact continuation. The exported reader graph remains unchanged; this preflight did not perform TF/TFLite conversion or recognition evaluation.

The two generated one-step checkpoints remain diagnostic artifacts in the private work directory and are deliberately excluded from this archive. Their sizes and hashes are listed in the index, and they must never initialize training or become active.
