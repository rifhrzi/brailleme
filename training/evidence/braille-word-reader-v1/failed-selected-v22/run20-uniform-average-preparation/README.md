Satu kandidat rata-rata bobot run20 epoch 8, 9, 10, dengan koefisien tepat 1/3 masing-masing. Ini rata-rata checkpoint dari satu lintasan training, bukan ensemble inferensi dan bukan pencarian subset/koefisien. Plan dibekukan sebelum kandidat ditulis; checkpoint sumber tetap utuh.

[Wortsman et al., ICML 2022](https://proceedings.mlr.press/v162/wortsman22a/wortsman22a.pdf), §2, §3.3, §5–6, mendukung gagasan rata-rata bobot model dengan inisialisasi bersama pada tugas klasifikasi. Paper utamanya menggabungkan hasil fine-tuning independen; proposal kita menggabungkan tiga epoch dari satu run. Paper memperingatkan uniform average dapat memburuk bila komponennya buruk/terpisah dalam ruang loss, dan tidak memberikan perbaikan kalibrasi setara ensemble. Hasil image/text classification tersebut tidak membuktikan peningkatan deteksi Braille, exact-word, atau ketepatan hasil yang diterima. Pembacaan sumber ini hanya memberi hipotesis murah untuk diuji.

`prepare.py` hanya membaca zip/HDF5 dan audit sampling: ketiga epoch memenuhi full-cycle coverage; semua path/shape/dtype dari 280 array model cocok; graph sama; 208 array pada 52 BatchNorm beku identik byte. `inventory.json` menyimpan path HDF5, nama/path layer dalam konfigurasi dan indeks variabel tersimpan, bukan menebak nama variabel dari urutan global. Compile config optimizer epoch10 mempunyai learning rate berbeda; graph di luar compile config tetap identik.

`average.py` mempromosikan 72 array non-BN ke float64, menjumlahkan dalam urutan epoch 8→9→10, membagi tiga, lalu satu kali cast ke float32. Seluruh array BN disalin persis dari epoch9. Group optimizer HDF5 dihapus dari salinan dan compile_config dikosongkan; 146 dataset optimizer tidak ikut rata-rata. Hasil hanya untuk inferensi, dilarang sebagai sumber resume training. Keberadaan satu bundle tidak membuktikan bahwa Keras sudah memuat atau menjalankannya: tahap ini hanya memeriksa graph/HDF5, roundtrip seluruh array, serta oracle aritmetika skalar independen.

Urutan evaluasi dibekukan: run26 selesai → hasil selected-v21 menjadi kontrol pertama → bandingkan hanya kontrol tersebut dan kandidat ini pada 405 fixture serta grid weak-peaks-v2 yang sama → selected-v22. Hash kontrol aktual perlu diikat dalam protokol tambahan setelah selected-v21 ada. Tie tetap memilih kontrol pertama. Belum ada evaluasi 405, pembacaan piksel/label fixture, ekspor TF/TFLite, atau evaluasi 607/44/66 dalam pekerjaan ini.

Sebelum klaim apa pun: reviewer independen memeriksa seluruh aritmetika/path/sumber/BN dan ketiadaan optimizer; loader Keras compile=False kemudian harus memuat graph yang identik; seleksi dan seluruh gate konversi/native/akurasi yang sudah berlaku tetap diperlukan. Rata-rata ini merupakan turunan dari tiga checkpoint eligible, bukan epoch training baru atau bukti coverage baru. Tidak ada pelonggaran gate atau perubahan aplikasi.
